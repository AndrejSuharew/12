## Описание проекта
В рамках данной лабораторной работы спроектирован процесс работы команды и сформирован математически обоснованный план выпуска MVP для автоматизированного таск-трекера **«OptiPlan»**. В ходе работы применены методы относительной и вероятностной оценки, приоритизации, а также алгоритмы линейного программирования и статистического моделирования потока задач.

Отчётом о выполнении лабораторной работы служит набор взаимосвязанных Markdown-документов, расположенных в каталоге `docs/01-planning/`. Все расчеты, графики и структуры полностью воспроизводимы с помощью скриптов, находящихся в папке `scripts/`.

## Навигация по отчетным документам (Этап 1)

Для проверки хода выполнения работы перейдите по ссылкам ниже:

1. [Видение продукта (vision.md)](docs/01-planning/vision.md)
   * **Содержимое:** Целевая аудитория, описание ключевой проблемы, сценарии использования, измеримые KPI успеха и границы проекта (Out of Scope).
   * **Карта историй:** Интегрированная таблица User Story Map и текстовое обоснование горизонтальной линии MVP.
2. [Рабочее соглашение команды (team-agreement.md)](docs/01-planning/team-agreement.md)
   * **Содержимое:** Ритм синхронизации, регламент коммуникаций в Telegram, правила проведения код-ревью, распределение ответственности и матрицы замещения между Андреем и Даниилом.
3. [Обоснование процесса (process.md)](docs/01-planning/process.md)
   * **Содержимое:** Обоснование выбора методологии Scrumban. Математический расчет и аргументация WIP-лимитов для колонок «В работе» и «Ревью» с использованием **закона Литтла**. Формализованные критерии готовности задач **Definition of Ready (DoR)** и **Definition of Done (DoD)**.
4. [Оценка трудоёмкости (estimates.md)](docs/01-planning/estimates.md)
   * **Содержимое:** Протокол совместной сессии Planning Poker в Story Points по шкале Фибоначчи для всех 15 историй бэклога. Вероятностная **трёхточечная оценка PERT** (ожидаемая длительность, отклонение и дисперсия в абсолютных часах) для 5 наиболее неопределенных задач.
5. [Приоритизация и состав релиза (prioritization.md)](docs/01-planning/prioritization.md)
   * **Содержимое:** Расчет индексов **WSJF** с обоснованием. Определение математической емкости команды. Формальная постановка **задачи о рюкзаке** (целевая функция максимизации ценности, ограничения по емкости и технологические зависимости). Сравнение оптимального решения (`release_planner.py`) с «жадным» алгоритмом.
6. [Сетевой график и вероятностный прогноз (release-plan.md)](docs/01-planning/release-plan.md)
   * **Содержимое:** Расчет ранних/поздних сроков стартов и финишей задач, определение **критического пути** и временных резервов (CPM). Расчет точной вероятности завершения MVP к дате защиты по методу PERT. Результаты 10 000 симуляций **Монте-Карло** с указанием дат для 50% и 85% вероятности.

## Как проверить воспроизводимость расчетов

Все алгоритмы оптимизации могут быть перезапущены локально. Для этого:
1. Установите необходимые зависимости (если применимо): `pip install -r requirements.txt` (или используйте стандартные библиотеки Python, заложенные в скрипты).
2. Исходные данные по весам, ценности и зависимостям историй находятся в файле `data/tasks_data.csv`.
3. Для генерации отчетов запустите соответствующий скрипт из папки `scripts/`, например:
   ```bash
   python scripts/release_planner.py
   python scripts/pert_cpm.py
   ```
